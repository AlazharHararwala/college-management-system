About this project

CampusHub is a college management system I built to learn how backend and frontend technologies fit together: Flask routing and sessions, SQLAlchemy models on MySQL, and Jinja templates for student, faculty and admin portals. It is a learning project, not a production system. Built by Alazhar Hararwala.
